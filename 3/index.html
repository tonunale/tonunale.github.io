Global Crop & Culinary Explorer

Topic Description

Food is an indispensable aspect of the life of all human beings, but consumers today have become less and less aware of the agricultural background of the foods they eat on a daily basis. It is extremely important to learn about the historical and geographic backgrounds of staple crops in order to understand culinary heritage, environmental issues, and the interdependence of global agriculture. The purpose of this web application, which is called the Global Crop & Culinary Explorer, is to help users learn about the origin of staple crops and the influence of these crops on cuisines around the globe. People today eat food without realizing that it took decades of cultivation, transportation, and development to make it available.

Despite there being numerous recipe sites and agriculturist sources available, not many are able to integrate the two into an educational experience. Websites like recipe sites are more concerned about presenting recipes than giving any context to the origin of their raw materials. On the other hand, botanical sites can be too much in terms of their vocabulary and understanding for an average individual. This is where this application comes into play by offering users a visual experience.

App Description

The intended website application is supposed to be built based on four main pages which will assist the users to have a tour in global agriculture history and geography.

  1. Homepage: This will be an introductory page for the user which contains the welcoming messages along with a hero picture of a global spice/crop market. There will also be some navigation options which will help the user to move ahead.
  2. Interactive Crop Explorer: This page enables the user to explore global agriculture through a two-stage selection process.
    • Stage One (Region): The Americas, Asia, Europe, Africa
    • Stage Two (Staple Crop):
      • The Americas: Corn, Potatoes, Tomatoes, Cacao
      • Asia: Rice, Soybeans, Tea, Ginger
      • Europe: Wheat, Grapes, Olives, Oats
      • Africa: Sorghum, Yams, Coffee, Millet
    • Final Output: All the 16 choices will give the user an image of the crop, a traditional recipe name made from that crop, and a paragraph on the historical importance of the crop.
  3. Farming Techniques (Read-Only): This page is going to be a source of information about ancient farming techniques. This page will include text and historical images which users can read.
  4. Contact Us: A contact page that will have a form allowing the user to enter their Name, E-mail address and a box to "suggest a crop" for the database.
